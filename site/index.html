What you'll learn

An AI agent does more than chat — it takes steps toward a goal. It can look things up, do calculations, write drafts, and decide what to do next based on the results. This guide walks you through the five building blocks, in order:

Step What it means Read
1. What an agent is The difference between an assistant that answers and an agent that acts. Intro →
2. Planning Breaking a goal into small, ordered steps. Planning →
3. Tool use Giving the agent tools to search, calculate, write. Tool use →
4. Memory Remembering what matters from one step to the next. Memory →
5. Safety Keeping the agent helpful and harmless. Safety →
Bonus. MCP A simple way to connect agents to tools and data. MCP →
No coding required to start You can design your first agent with paper and a pen. The printable worksheet at the end walks you through it. Coding comes later — only if you want it.

Who this is for

Anyone curious about AI agents who wants to understand how they work before writing a single line of code. Written for complete beginners, in plain English, step by step, never condescending.
