# Building Simple AI Agents: A Beginner's Manual

A plain-English, step-by-step guide to planning, tool use, memory, and safety for AI agents — no coding required to start. Includes an MCP (Model Context Protocol) overview and a printable agent-design worksheet.

## Who this is for

Anyone curious about AI agents who wants to understand how they work before writing a single line of code. Written for complete beginners, in plain English, step by step, never condescending. If you can write a to-do list, you can design an agent.

## What's inside

- `docs/` — the full manual as Markdown:
  - `00-intro.md` — What an AI agent is (and isn't)
  - `01-planning.md` — Breaking a goal into steps
  - `02-tool-use.md` — Giving an agent tools to act
  - `03-memory.md` — Remembering what matters
  - `04-safety.md` — Keeping agents helpful and harmless
  - `05-mcp.md` — MCP overview: connecting agents to tools and data
  - `06-worksheet.md` — Printable agent-design worksheet
- `site/` — the same guide as a static HTML website (no build step; just open `site/index.html` in your browser)

## How to use this guide

Read it in order, or jump to the section you need. Each section builds on the last, but you can start anywhere. The worksheet at the end is meant to be printed and filled out with a pen — no computer required.
