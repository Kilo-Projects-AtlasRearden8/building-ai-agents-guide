# Safety: Keeping Agents Helpful and Harmless

Agents act on your behalf, which means they can make mistakes with real consequences. Safety is the layer that keeps those consequences small and reversible.

## The ground rules

1. **A human approves consequential actions.** Sending email, spending money, deleting files, or changing records happens only after you say yes. The agent drafts; you decide.
2. **Never medical advice.** This guide and any agent built from it are for education only. An agent can help organize paperwork or find public health information; it cannot diagnose, treat, or give medical guidance. If it's about health, a qualified professional decides.
3. **Privacy by default.** Don't give agents passwords, account numbers, or personal details about real people. Treat agent memory like a shared notebook, not a vault.
4. **Reversible actions first.** Prefer tools that draft, preview, or export over tools that delete or publish. If something can't be undone, it needs extra approval.
5. **You can stop anytime.** An agent should be easy to pause, review, and switch off.

## Common beginner mistakes to avoid

- Letting an agent send email on its own "to save time"
- Giving an agent access to accounts it doesn't need
- Trusting an agent's answers without checking (agents can state wrong things confidently)
- Storing sensitive data in agent memory

## If something goes wrong

Stop the agent, review what it did, and decide whether any action needs to be undone or reported. Mistakes are normal when learning; the safety layer keeps them small.
