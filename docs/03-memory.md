# Memory: Remembering What Matters

Memory is what lets an agent carry context from one step to the next, and from one conversation to another. Without memory, every new message starts from scratch.

## Two kinds of memory

**Short-term memory** is what's happening right now. If you tell an agent your name at the start of a conversation, short-term memory lets it use your name ten minutes later without asking again.

**Long-term memory** is what sticks around after the conversation ends. If you tell an agent you prefer plain English summaries, long-term memory lets it remember that preference next week.

## How memory works in practice

Most agents remember by reading back what was written down — earlier messages in the conversation, notes in a file, or entries in a simple list. The agent doesn't "remember" like a person does; it re-reads a record you or it created earlier.

## What to remember (and what not to)

Good things to remember:

- Your name and preferred way of being addressed
- The goal you're working toward
- Steps already completed
- Decisions you've made ("use budget airlines only")

Things agents should not store:

- Passwords, credit card numbers, Social Security numbers
- Medical details about real people
- Anything you wouldn't write down and leave on a desk

## You stay in control

You can always review what an agent has remembered, correct it, or delete it. Memory is a tool for you, not a secret file the agent keeps.
